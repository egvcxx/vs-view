# 翻译文本对照表

用于纯文本审阅，不涉及代码语法。两个文件均为 UTF-8、制表符分隔（TSV），
可用任意文本编辑器、VS Code、Excel 或 LibreOffice 打开。

| 文件 | 内容 | 行数 |
|---|---|---|
| `界面文本对照.tsv` | 软件界面英文原文与中文译文 | 398 |
| `文档文本对照.tsv` | 文档逐块英文原文与中文译文 | 1136 |

## 列说明

### 界面文本对照.tsv

| 列 | 说明 |
|---|---|
| 序号 | 稳定编号，反馈时可直接引用 |
| 英文原文 | 同时是程序查表用的键，**请勿修改**；如需改英文，需要同步改源码 |
| 中文译文 | 审阅对象，可直接改这一列 |
| 使用位置 | 该字符串在源码中的位置（`文件:行号`）；标为“未在源码中找到”的多为动态拼装或暂未使用 |

### 文档文本对照.tsv

| 列 | 说明 |
|---|---|
| 序号 | 稳定编号 |
| 页面 | 对应 `docs/zh/` 下的页面 |
| 类型 | 标题、段落、列表项、表格行、提示框、图片说明等 |
| 英文原文 | 上游 `docs/` 对应块 |
| 中文译文 | `docs/zh/` 对应块，审阅对象 |
| 备注 | 仅在有特殊情况时填写，见下 |

备注含义：

- `中文版新增，无英文原文`：中文版有意添加的提示（目前共 7 处，均为“非官方翻译”“网络环境”“API 页保持英文”等说明）。
- `中文版专有页面，无英文原文`：`translation.md`（关于本翻译）没有英文版本。
- `英文原稿有、中文版缺失`：自动对齐发现的不一致，正常情况下应为 0。
- `自动对齐存疑` / `类型不一致`：自动对齐不确定，需要人工核对；正常情况下应为 0。

## 如何批注

任选一种：

1. **直接改译文**：编辑“中文译文”列后保存，附上序号说明改动原因。
2. **新增批注列**：在最后一列后加一列 `批注`，写入意见，保留原译文便于对照。
3. **单独列清单**：按 `序号: 原句 -> 建议` 的格式反馈即可。

界面文本的英文原文是查表键，改动它会导致译文失效；如果认为英文原文本身需要调整，
请单列出来，作为上游改动另行处理。

## 覆盖范围说明

- 界面文本共 398 条。其中 161 条通过字面 `tr("...")` 调用，其余多由设置模型、插件元数据等
  以数据形式传入 `tr()`，因此“使用位置”只表示首次出现的位置，不保证是唯一调用点。
- 文档为逐块对照；代码块、命令、配置键与标识符原样保留，不进入对照表。
- 文档中的界面名称按约定保留英文，方便与英文截图对照；软件内启用中文后，实际界面会显示中文。

## 与上游协作

如果上游愿意接受纯文本而不接受代码分支，可直接提交本目录的两个 TSV（或等价 JSON）作为
翻译初稿，由上游决定 i18n 实现方式。`界面文本对照.tsv` 的“英文原文”列即为建议的查表键。
