# 插件

<strong>VSView</strong> 提供插件系统，可扩展其功能。插件可以添加新工具、自定义 UI 面板，并与视频、音频处理管线集成。

## 插件分类

插件按其来源与维护层级分类：

- [<strong>第一方（官方）</strong>](first-party.md)：直接集成在 <strong>VSView</strong> 源码中。
- [<strong>第二方</strong>](second-party.md)：由社区成员在官方仓库中开发，但作为独立包维护。
- [<strong>第三方</strong>](third-party.md)：由社区中的独立开发者创建。

## 开发插件

参阅[插件开发](development.md)指南，了解如何创建并注册 <strong>VSView</strong> 插件。

也可以使用这个[插件模板](https://github.com/Ichunjo/vs-view-plugin-template)来搭建项目骨架。
